# Букинистика: «Литературные памятники» и Academia (до 1937)

Пакет для ручного поиска на Авито и Мешке. Покупок нет, живые объявления не парсились,
все цены — экспертные ориентиры «средняя / максимум», а не выгрузка с площадок.

## Файлы

| Файл | Что внутри |
|---|---|
| `01_reference_list.md` | 50 позиций: автор, название, год, издательство + 3–5 поисковых фраз к каждой |
| `02_price_table.md` | сводная таблица с ценами, тиражами и примечаниями |
| `03_lots_and_checklist.md` | 3 разбора многокнижных лотов + чек-лист из 8 пунктов |
| `04_avito_catalog_ext.md` | ещё 24 редких издания (1872–1993, журналы, энциклопедия, «Литературные памятники») без цен — только для матчинга |

Каталог бота собирается из `02_price_table.md` (позиции 1–50) и
`04_avito_catalog_ext.md` (позиции 51–74) скриптом
`scripts/build_books_catalog.py` → `data/books_catalog.json`. У новых 24
изданий нет цен и точная дата может быть диапазоном («1906–1909»), поэтому
в уведомлении для них не показывается оценка стоимости.

Шесть последних позиций (69–74) добавлены по запросу владельца: Марк Аврелий
«Размышления» (1985, Ленинград; 1993, СПб.), Цицерон «Письма…» т. II (1950)
и т. III (1951), Махабхарата кн. 4 «Виратапарва» (1967) и кн. 5
«Удьйогапарва» (1976) — все издания «Наука», серия «Литературные памятники».
Матчинг для них строгий: «Размышления» требует автора, тома Цицерона
различаются номером тома, книги Махабхараты — названием главы; голое
«Махабхарата» или «Письма к Аттику» без тома/главы не считается совпадением.
Репринты и факсимиле отсекаются общим фильтром («репринт», «факсимиле»,
«переиздание») и годом издания вне ожидаемого диапазона.

## Логика отбора

**«Литературные памятники» (Наука)** — 26 позиций, почти всё 1948–1965. Серия началась в 1948-м,
ранние тома печатались тиражами 2 500–10 000 экз., многие с суперобложкой, которая почти
не сохраняется. Отобраны тома с тиражом ≤5 000 экз. (редкие) и «якорные» академические издания,
которые всегда спрашивают (Цезарь, Катон, Монтень, Старшая Эдда).

**Academia (1922–1937)** — 24 позиции. Это не «просто старые книги», а библиотечные
памятники: малотиражные (300–5 300 экз.), с авторской графикой, часть тиражей уничтожена.
Отобраны три типа:
1. античные и западные классики в переводах 1920–30-х (Апулей, Катулл, Аристофан, Гелиодор);
2. искусствоведческие альбомы (Фаюмский портрет, Сасанидский металл, Палех);
3. репрессированные/уничтоженные тиражи (Фацетии — 300 экз., Вико, Борн).

Порог 4 500 ₽: все позиции в таблице имеют среднюю выше порога либо окупаются только
комплектом/томом в суперобложке — это помечено в примечании.

## Как читать цены

- «Средняя» — типичная сделка за один том в хорошем состоянии, без суперобложки.
- «Максимум» — комплект, суперобложка, отличная сохранность, провенанс, автограф/экслибрис.
- Наценки: суперобложка +30–50 %, полный комплект томов +50–120 %, «как новая» +20–30 %.
- Скидки: библиотечные штампы −20–40 %, разрывы/утраты корешка −30–50 %, «владельческий переплёт» −40 %.

## Проверка «живого» браузера

Реальный Chrome через nodriver (профиль `price_tracker/chrome_profile_avito`, флаги
`--disable-blink-features=AutomationControlled`, без JS-инъекции — `_inject_stealth()`
сейчас no-op) открыл главную Авито без капчи:
заголовок «Авито: недвижимость, транспорт, работа, услуги, вещи», город в шапке — Астрахань.
Значит связка «реальный Chrome + сохранённый профиль» рабочая; при ручном поиске достаточно
этого же профиля и паузы 6–12 секунд между запросами.
