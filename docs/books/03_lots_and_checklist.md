# Многокнижные лоты: 3 разбора + чек-лист

Ниже — типовые шаблоны описаний (не цитаты реальных объявлений). Задача: за 2–3 минуты
понять, есть ли в лоте позиция из эталонного списка и сколько она стоит.

---

## Пример 1. «Старые книги из библиотеки, всё вместе»

> Продам книги из домашней библиотеки. Всего 14 штук. Есть старые, есть поновее.
> Фото общие, по отдельности не продаю. Цена за всё — 6 000. Самовывоз.
> В наличии: «Записки о Галльской войне», «История одного города», «Мёртвые души»,
> «Слово о полку Игореве», пара томов «Библиотеки всемирной литературы», справочники,
> ещё что-то по истории.

**Разбор.** Ключевое слово — «всё вместе»: продавец не сегментирует, значит за 6 000 можно
забрать 1–3 ценных тома. Фото общие — просим фото корешков и титульных листов.

| Что выписываем | Как заполнять |
|---|---|
| Автор | Из названия; если не указан — «—» и уточняем по титулу |
| Название | Дословно, без «сокращений» |
| Год | Только с титульного листа/колофона, не с обложки |
| Издательство | «Наука» / «Academia» / «Академия» — важно для серии |
| Средняя/макс. | По таблице; для непонятного тома — «н/д, нужен год» |
| Примечание | «в лоте 14 книг, цена 6 000 → доля 430 ₽/книга; проверить 1948/1950» |
| Поисковый запрос | `Слово о полку Игореве 1950` + `Записки о Галльской войне 1948` |

**Что настораживает:** «по отдельности не продаю», нет титулов, «справочники» —
скорее всего балласт. **Что радует:** 1948–1950-е в списке, цена за лот ниже стоимости
одного целевого тома.

## Пример 2. «Academia, 1930-е, пять книг с суперобложками»

> Продаю пять книг издательства Academia, 1930-е годы. Состояние хорошее,
> суперобложки потрёпаны. В составе: «Декамерон» (2 тома), «Гулливер»,
> «Дон Кихот», «Морфология сказки», «Слово о полку Игореве» (Палех).
> Цена 9 500 за всё. Торг.

**Разбор.** Здесь главное — не цена, а комплектность и подлинность. «Декамерон» 2 тома —
это 1927, «Гулливер» — 1928, «Дон Кихот» — 1929 (часто только т. 1), «Морфология сказки» —
1928 (1 600 экз., сама по себе 15 000+), «Слово о полку» — 1934 (3 300 экз., 25 000+).
Лот стоимостью 9 500 — почти наверняка «золото» либо подделка/репринт.

| Поле | Значение для «Морфологии сказки» |
|---|---|
| Автор | В. Пропп |
| Название | Морфология сказки |
| Год | 1928 (проверить: переиздания 1969, 2001) |
| Издательство | Academia, Ленинград |
| Средняя | 15 000–22 000 |
| Максимум | 40 000 (с суперобложкой, отл.) |
| Примечание | 1 600 экз.; в лоте 5 книг за 9 500 — приоритет №1, проверить подлинность |
| Запрос | `Пропп Морфология сказки 1928 Academia` |

**Красные флаги:** «репринт 1990-х» с тем же логотипом, отсутствие выходных данных,
суперобложка «потрёпана» на всех книгах сразу, цена ниже рынка в 3 раза, продавец
отказывается дать фото титула и колофона.

## Пример 3. «Литературные памятники, 8 томов, 1950–60-е»

> Собрание «Литературные памятники», 8 книг. «Махабхарата» (2 тома), «Старшая Эдда»,
> «Шицзин», «Артхашастра», «Кабус-намэ», «Монтень. Опыты» (2 книги). Все в хорошем
> состоянии, без суперобложек. 22 000 за собрание, возможно по отдельности.

**Разбор.** Считаем не «за собрание», а по позициям: Махабхарата 2 т. (12 000–20 000),
Старшая Эдда (7 000–10 000), Шицзин (6 500–9 500), Артхашастра (5 500–8 000),
Кабус-намэ (5 000–7 500), Монтень 2 кн. (12 000–18 000). Итого 48 000–73 000 при
покупке за 22 000 — запас 2–3×.

| Поле | «Старшая Эдда» |
|---|---|
| Автор | — (сборник) |
| Название | Старшая Эдда |
| Год | 1963 |
| Издательство | Наука (ЛП) |
| Средняя | 7 000–10 000 |
| Максимум | 16 000 (суперобложка, отл.) |
| Примечание | 3 000 экз.; без суперобложки — минус 25–35 %; в лоте 8 книг за 22 000 |
| Запрос | `Старшая Эдда 1963 Наука` |

**Правило деления:** цена лота / число целевых книг. Если «доля» ниже средней цены
позиции в 2 раза — лот интересен даже с балластом.

---

## Чек-лист ручного поиска (8 пунктов)

1. **Фильтр по году в заголовке.** Смотрите только объявления, где есть 1948–1965 (ЛП)
   или 1922–1937 (Academia). «Старинные книги», «СССР», «ретро» — открывать в последнюю очередь.
2. **Проверка издательства.** «Наука» + «Литературные памятники» = серия; «Academia»/«Академия» +
   Ленинград/Москва = оригинал. Если «Академия» без года — почти всегда репринт 1990-х.
3. **Год — только по титульному листу и колофону (последняя страница).** Год на корешке,
   обложке и в тексте объявления не считается: у ЛП часто переиздания 1970–80-х.
4. **Тираж — в колофоне, строка «Тираж … экз.».** Для ЛП: ≤5 000 — цель, 5 000–10 000 — средне,
   >20 000 — мимо. Для Academia: ≤3 300 — приоритет, 5 000–10 000 — смотреть по названию.
5. **Комплектность.** Для многотомников сразу спрашивайте: «все тома? какие именно?»
   Один том из 8 — это −60 % к цене комплекта, но всё равно может быть выгодно.
6. **Состояние в 4 вопросах:** суперобложка есть? корешок цел? страницы все? штампы/утраты?
   Ответы «не знаю» = торг и риск, закладывайте −30 %.
7. **Многокнижный лот — делить на позиции.** Выпишите каждую книгу отдельной строкой,
   поставьте год/тираж, посчитайте сумму по «средней». Если сумма ≥2× цены лота — брать.
8. **Проверка продавца.** Профиль >1 года, есть отзывы, фото титула по запросу, не «оптовик»
   с сотней одинаковых лотов. Отказ показать колофон — стоп.

### Мини-шпаргалка «стоп-сигналы»

- «Репринт», «переиздание», «современная копия», «факсимиле» — не то.
- Цена 500–1 500 ₽ за «Academia 1930-х» — либо репринт, либо убитый экземпляр.
- Все книги в лоте «в идеале» и 1930-х — настороженность: проверяйте бумагу и шрифт.
- Продавец не даёт фото колофона/титула — пропускаем.
- «Продаю всё одним лотом, по одной не надо» при цене выше рынка — пропускаем.

### Как быстро считать выгоду

`Выгода = Σ(средняя цена целевых книг) − цена лота − 15 % (торг/доставка/чистка)`

Если < 0 — мимо. Если 0–30 % — только при идеальном состоянии. Если >50 % — брать.
