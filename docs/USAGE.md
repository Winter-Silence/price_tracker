# Работа с проектом

> [Что за проект](PROJECT.md) · [Как установить](INSTALL.md) · **Как работать**

## Запуск

```bash
# bash / zsh:
source venv/bin/activate
# fish:
source venv/bin/activate.fish

python main.py
```

Бот и планировщик работают в одном event loop. При старте:

1. Инициализируется БД (создаются таблицы)
2. Запускается планировщик — раз в `POLL_INTERVAL_MINUTES` минут опрашивает цены всех активных товаров
3. Запускается Telegram-бот — реагирует на команды пользователей

## Команды бота

| Команда | Описание |
|---|---|
| `/start` | Приветствие и краткая инструкция |
| `/help` | Подробная помощь по командам |
| `/add` | Добавить товар для отслеживания (многошаговый диалог) |
| `/list` | Список отслеживаемых товаров с текущими ценами |
| `/delete` | Удалить товар (с подтверждением через inline-кнопки) |
| `/history` | История цен для товара |

### Добавление товара (`/add`)

1. `/add` — бот просит ссылку на товар
2. Отправьте URL товара (Wildberries, Ozon, Citilink)
3. Введите название товара (для удобства, отображается в `/list`)
4. Введите пороговую цену — бот уведомит, когда цена упадёт ниже этого значения. Введите `0`, чтобы просто отслеживать цену без уведомлений
5. Товар добавлен — бот будет проверять цену каждый час (или другой интервал из `POLL_INTERVAL_MINUTES`)

### Удаление товара (`/delete`)

1. `/delete` — бот показывает inline-кнопки со всеми товарами
2. Выберите товар — бот запросит подтверждение
3. Подтвердите — товар деактивируется (мягкое удаление, `is_active = 0`)

### История цен (`/history`)

1. `/history` — бот показывает inline-кнопки со всеми товарами
2. Выберите товар — бот покажет последние 10 записей цен с датами

## Книжный режим (`/books`)

Команда добавляет поисковую ссылку Avito, по которой бот ищет только книги из
эталонного списка (68 позиций: 50 книг «Литературных памятников» 1948–1965 и
Academia 1922–1937 + 18 редких изданий без цен). Ссылка должна быть на всю
Россию и с сортировкой по дате, например:

```
https://www.avito.ru/rossiya/knigi_i_zhurnaly?q=литературные+памятники&s=104
```

Что происходит дальше:

1. Первый опрос просто запоминает текущую выдачу — старые объявления не проверяются.
   Первый глубокий обход существующей ссылки тоже проходит как «базовая линия»:
   бот записывает найденное, но не присылает уведомлений.
2. По расписанию `AVITO_BOOKS_POLL_INTERVAL_MINUTES` (по умолчанию — каждые 5 минут)
   бот листает выдачу вглубь (до 10 страниц) и останавливается, как только
   страница состоит только из уже известных объявлений. Параметры сортировки и
   фильтров (`s`, `f`, `context`, `cd`, `localPriority`, `q`) остаются нетронутыми —
   меняется только номер страницы. Бюджет домена — 4 запроса страниц (повторные
   запросы тоже расходуют лимит) и 8 карточек за цикл — общий на все книжные
   ссылки, а порядок ссылок сдвигается по кругу, чтобы он доставался всем, а не
   только первой. Книжный обход идёт отдельной задачей и использует отдельный
   доверенный профиль `chrome_profile_avito_books/`; обычный опрос `/add`
   продолжает использовать `chrome_profile_avito/`. Поэтому у режимов разные
   процессы Chrome и `SingletonLock`, и они не ждут друг друга. Любой запрос Avito
   (и книжный, и ценовой) ограничен таймаутом 75 с: при зависании завершается
   только Chrome этого профиля, его блокировки очищаются без удаления cookies,
   а текущий проход прерывается — следующий цикл начинает новую сессию. Ценовой
   опрос от этого не задерживается, но два Chrome-сеанса с одного IP могут чаще
   срабатывать антибот Avito. Если в `.env` оба профиля (`AVITO_PROFILE_DIR` и
   `AVITO_BOOKS_PROFILE_DIR`) указаны одинаковыми, книжный режим не запускается:
   в лог пишется ошибка, администратору уходит уведомление.
3. Сначала — только заголовок: если в нём нет ни книги/автора из списка, ни
   серии/издательства (Литературные памятники, Academia), ни антикварного или
   коллекционного маркера («из домашней библиотеки», «подборка книг»,
   «одним лотом»), карточка не открывается вообще — так бот не скрапит лишнее и
   не получает бан. Прошедшие фильтр карточки проверяются:
   - дату публикации (старше 24 ч — пропуск, неизвестная дата — пометка);
   - отзывы продавца (50+ — пропуск, это оптовик);
   - совпадение названия и описания с эталонным списком.
4. Уведомление приходит только если у совпадения есть подтверждение издания: год
   издания, издательство/серия или примета издания. Совпадение только по названию
   или «название + автор» («Робинзон Крузо» без года, Эксмо 2023) — современное
   переиздание, такое молча пропускается. Слово «издательство» должно стоять
   рядом с названием: «Академия» в другом абзаце лота изданием не считается.
5. Спорные совпадения (название совпало, а год/издательство не указаны, или в
   каталоге два одноимённых издания) бот не присылает сразу: он ставит лот в
   очередь и проверяет его через ИИ (бесплатные модели OpenCode: сначала kilo,
   затем nvidia, потом opencode). Уведомление придёт только если ИИ подтвердит,
   что это именно нужное издание. Если лимит бесплатных моделей исчерпан, бот
   ждёт и пишет об этом в Telegram — покупать доступ он не будет.
6. Если лот об одной книге, описание разбирается целиком: год из любого абзаца
   считается годом этого издания (подтверждает его или отсекает лот как
   переиздание). Если книг несколько, каждая позиция разбирается отдельно, чтобы
   год одной книги не приписался соседней.
7. При совпадении приходит уведомление с ценой лота, оценкой стоимости,
   уверенностью совпадения и ссылкой. Для книг без эталонной цены (новые 18
   позиций) строки с оценкой не показываются. Слабые совпадения помечаются
   «⚠️ Требует проверки», неизвестный год — «уточнить год».
8. Если в лоте несколько книг, показываются все позиции и суммарная оценка.

Оценка стоимости — ориентир по эталонному списку, а не гарантия цены.
Для калибровки без уведомлений: `AVITO_BOOKS_DRY_RUN=1`.
Проверку через ИИ можно отключить: `AVITO_BOOKS_LLM_ENABLED=0`.

## Уведомления

Когда цена товара опускается ниже пороговой, бот отправляет сообщение:

```
🔔 Цена упала!

📦 Пылесос Kärcher WD 3
🏪 ozon
💰 Текущая цена: 5490.00₽
🎯 Твоя цель: 6000.00₽

🔗 Перейти к товару
```

После срабатывания алерт деактивируется (повторных уведомлений не будет — нужно поставить новую цель через `/add`).

## Ручной тест парсера

Скрипт для проверки парсеров без запуска бота:

```bash
python scripts/test_parsers.py "https://www.wildberries.ru/catalog/12345678/detail.aspx"
python scripts/test_parsers.py "https://www.ozon.ru/product/nazvanie-833683323/"
```

Вывод при успехе:

```
Parser: OzonParser
Marketplace: ozon
URL: https://www.ozon.ru/product/...
Price: 5490.00
```

Если цена не получена (капча, ошибка, нет в наличии):

```
Price: not available
```

## Скриншоты при ошибках

При ошибках парсинга (капча, таймаут, не найден элемент цены) парсер автоматически делает full-page скриншот и сохраняет его в `screenshots/`:

```
screenshots/
├── ozon_captcha_20260626_161318.png
├── ozon_error_20260626_161318.png
└── wildberries_error_20260626_161307.png
```

Формат имени: `<marketplace>_<label>_<дата>_<время>.png`

Метки:

- `captcha` — обнаружена капча
- `error` — неперехваченное исключение
- `no_price_element` — не найден элемент цены на странице
- `no_connection` — страница «нет соединения» (Ozon)

## Добавление нового маркетплейса

1. Создайте файл в `parsers/` (например, `dns.py`)
2. Наследуйтесь от `BaseParser`:

```python
from parsers.base import BaseParser
from utils.logger import logger


class DnsParser(BaseParser):
    marketplace = "dns"

    @classmethod
    def can_handle(cls, url: str) -> bool:
        return "dns-shop.ru" in url

    async def get_price(self, url: str) -> float | None:
        await self._random_delay()
        page = await self._get_page(url)
        try:
            price_text = await self._eval(page, '''
                (() => {
                    let el = document.querySelector("YOUR_SELECTOR");
                    return el ? el.innerText.trim() : null;
                })()
            ''')
            if not price_text:
                return None
            # логика парсинга цены из price_text
            price = ...
            return float(price)
        except Exception as exc:
            logger.error("DNS parser failed for %s: %s", url, exc)
            await self._take_screenshot(page, "error")
            return None
        finally:
            await self._close()
```

3. Зарегистрируйте в `parsers/__init__.py` — добавьте класс в список `PARSERS` и импорт
4. Протестируйте: `python scripts/test_parsers.py "<url>"`

> **Stealth-инъекции сейчас нет** — `_inject_stealth()` в `BaseParser.start_session()`
> вызывается, но это пустая заглушка: JS-антидетект (`STEALTH_JS`) не инжектится
> (его отключили из-за WAF-защиты Wildberries). Работают только Chrome-флаги
> (`--disable-blink-features=AutomationControlled` и др.) и запуск настоящего
> Chrome в обычном режиме под Xvfb. Дополнительных действий от нового парсера
> не требуется.

Если маркетплейс отдаёт цену по API (как Wildberries), переопределите `start_session()` / `end_session()` для использования `aiohttp.ClientSession` вместо браузера — см. `parsers/wildberries.py` как пример.
