## Наценки и скидки (применять к «средней»)

| Фактор | Коэффициент |
|---|---|
| Суперобложка в preserved виде (Academia, ЛП 1950-х) | +30–50 % |
| Полный комплект томов одного издания | +50–120 % |
| Футляр / коробка (Палех, альбомы) | +20–40 % |
| Автограф, экслибрис, провенанс | +50–200 % |
| Библиотечные штампы, кармашек | −20–40 % |
| Потёртости, надрывы корешка | −20–30 % |
| «Владельческий» коленкоровый переплёт | −40–60 % |
| Утрата суперобложки у Academia 1930-х | −25–35 % |

## Что заведомо НЕ брать по этим критериям

- ЛП 1970–1990-х тиражами 20 000–100 000 экз. (Пушкин, Толстой, Светоний, Прево «Манон Леско» 1967 и т. п.) — средняя 500–1 500 ₽.
- Academia «Сборники статей», «К постановке спектакля», каталоги выставок — узкий спрос, 1 500–4 000 ₽.
- Репринты и переиздания 1990–2000-х с логотипом Academia — не путать с оригиналами.
- Библиотечные комплекты без титульных листов и с утратой иллюстраций.
